Sociality : Social Media Frontend MVP

A modern social media web application developed as part of a Full-Stack Web Development Bootcamp assignment, following the frontend MVP requirements and API specifications provided by my mentor.

Sociality allows users to connect, share posts, interact through likes and comments, follow other users, and manage their personal profiles.

Beyond the required features, I also developed an additional Creator Insights experience to explore how statistical thinking and data analysis can enhance a social media application.

About This Project

This project was developed as a bootcamp assignment to demonstrate my understanding of frontend development, API integration, authentication, state management, and end-to-end user interactions.

The main objective was to build a functional social media frontend using the provided backend API while following the mentor's requirements for user experience, access control, and application behavior.

The project also serves as part of my ongoing learning journey and will be included in my personal software engineering portfolio.

Additional Feature — Creator Insights

Creator Insights is an independent extension that I added beyond the required bootcamp scope.

This feature explores how statistical analysis can support content creators in understanding their engagement data.

The additional experience includes:

Engagement summaries based on available post interactions

Post comparison tools

Interaction distribution analysis

Evidence-based recommendations with analytical caveats

Clear explanations of data limitations

The intention is not to present simple engagement metrics as causal evidence of content performance. Instead, the feature encourages careful interpretation of descriptive statistics and transparent communication of analytical limitations.

This extension reflects my interest in connecting software engineering with data analysis and statistical reasoning.
